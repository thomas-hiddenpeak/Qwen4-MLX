2026-09-07。真实 layer-0 输入上的 83 项有限值、形状和逐位比较通过，四组完整 MoE 算子中位倍率为 1.0203–1.0471，未达到预先约定的约 5% 可重复收益筛选量级。停止扩大本候选，不运行其整模型生成及状态测试，不改变默认路径。

最终提交只保留显式算子探针和所需 kernel。构建与实测时曾接入的 `batchedSharedElementwise` 生成模式及可选统计字段已撤下；五文件候选留在忽略的实验目录，不进入生成接口。现有 MTP 发布结论不变。

## 改动与复现

共享专家无需路由选择，但仍需 gate/up/down 投影、SwiGLU 和输出 gate。候选只在验证长度 S2/S3 合并 SwiGLU 和最终加权相加的逐元素节点，保持每个 BF16 舍入边界及既有 sigmoid 查表。投影、路由专家、归约、Attention、GDN 和提交逻辑均不改变。

复用 S1 的 Metal 算术源，新增按验证长度及诊断开关区分的缓存；输出 gate 按 token 行索引。测试通过显式开关选择该路径，未依赖默认关闭的 S1 shared fusion 初始化。旧 `tokenAxis` 探针仍为默认。

```sh
.build/release/ane-runner probe-gpu-moe-verification \
  --model-dir ../qwen38-ssd/models/Qwen3.8-Flash-Next-MLX-SSD-Stream \
  --candidate sharedElementwise --warmups 3 --runs 12 \
  --output NEW_REPORT.json
```

运行前由现有实验控制器交接唯一模型所有者；本轮结束已恢复原参考服务。输入为既有 `fixtures/moe-real/converted/prefill.json` 和 `decode.json` 的真实行，无新造的生成轨迹。

## 本轮结果

| 输入 | 基线中位 ms | 候选中位 ms | 基线/候选 | 差值 µs |
| --- | ---: | ---: | ---: | ---: |
| S2，不同行 | 0.4253335 | 0.4095000 | 1.038665 | 15.8335 |

每组每种实现 3 次预热、12 次测量，按 AB/BA 交错，共保留 24 次预热及 96 次测量。计时包含驻留原始 Q4 权重下的 Swift 图构建、GPU 执行和输出求值；不含模型加载和诊断张量回读。表中是整个 MoE 算子，不是尾部独占成本，也不是物理带宽或整模型吞吐。

每组 17 个诊断张量（含输出）和 3 个普通/诊断路径交叉比较，共 80 项；S3 后同对象返回 S2 再检查 3 项，全部有限且逐位相同。S2/S3 不同行的共享 gate 分别有 2/3 种位模式，实际覆盖了跨行 gate 索引；重复行只有一种是预期行为。

独立重算保留了所有样本。仅看 AB 与 BA 顺序时，S3 不同行的倍率分别为 1.031207 和 0.980723；该组基线前六/后六样本中位数从 1.022333 降到 0.4715205 ms，候选从 1.0720415 降到 0.4554375 ms，存在明显时序变化。因此连这组约 2.36% 的总体倍率也不能当成稳定收益。未删掉早期样本或重跑挑选结果。
